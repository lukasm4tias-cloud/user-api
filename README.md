# User API — Java e Spring Boot

API REST desenvolvida em Java utilizando o framework Spring Boot, como parte dos meus estudos em desenvolvimento de software back-end.

## Tecnologias utilizadas

- Java
- Spring Boot
- Maven
- APIs REST
- JSON

## Sobre o projeto

O projeto tem como objetivo praticar o desenvolvimento de aplicações back-end, a organização de classes Java e a criação de endpoints HTTP com Spring Boot.

## Estrutura

- **Controllers:** responsáveis por receber e responder às requisições HTTP.
- **DTOs:** utilizados para representar os dados transferidos pela aplicação.
- **Maven:** gerenciamento de dependências e construção do projeto.

## Como executar

1. Clone o repositório.
2. Abra o projeto em uma IDE compatível com Maven.
3. Configure um JDK compatível com a versão do Spring Boot utilizada.
4. Execute a classe principal da aplicação.
